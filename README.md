# Интерактивный веб-портал: Моя Беларусь

Учебный проект об истории, культуре и природном наследии Беларуси. Портал объединяет справочные материалы и интерактивные элементы, чтобы знакомство со страной было наглядным и удобным.

## Разделы проекта

- **История** — интерактивный таймлайн с ключевыми эпохами и событиями.
- **Культура** — материалы о белорусском искусстве, ремёслах и культурном наследии.
- **Туризм** — подборка природных и исторических мест с поиском дополнительной информации через Википедию.
- **Традиции** — календарные праздники, народный костюм и обычаи.
- **Викторина** — интерактивная проверка знаний о Беларуси.
- **Карта областей** — знакомство с регионами страны.

## Технологии

- React 19
- TypeScript
- TanStack Start и TanStack Router
- Tailwind CSS v4
- Lucide Icons
- Vite
- Vitest

## Запуск в Windows одним двойным щелчком

Запустите файл `start.bat` в корневой папке проекта. Скрипт проверит Node.js, при необходимости установит актуальную LTS-версию, установит зависимости, запустит сервер и откроет сайт в браузере. Для первого запуска нужен доступ в интернет.

## Запуск проекта

Установите Node.js 20 или новее, затем выполните команды в корневой папке проекта:

```bash
npm install
npm run dev
npm run test
npm run build
```

После запуска режим разработки будет доступен по адресу, который выведет Vite в терминале.

## Структура проекта

- `src/routes/` — страницы и маршруты приложения.
- `src/components/` — переиспользуемые компоненты интерфейса.
- `src/assets/` — изображения и видео проекта.
- `src/lib/` — данные, логика поиска и вспомогательные функции.
